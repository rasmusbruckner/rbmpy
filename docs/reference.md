# API Reference

Welcome to the API Reference of the `rbmpy` package.

- [Agent RBM Module](agent_rbm.md): Core classes for the Reduced Bayesian Model (RBM), including `AlAgent` and `AgentVars`.
- [Circular Regression Module](circular_regression.md): Circular regression components, including `RegressionParent`.
- [Task Module](task.md): Classes for the canonical change-point task, in particular `ChangePointTask` and `TaskVars`.
- [Utilities Module](utilities.md): Helper functions such as `compute_persprob`, `get_sel_coeffs`, `parameter_summary`, and `residual_fun`.
